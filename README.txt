MFONI gallery pages

Upload people.html, places.html and moments.html to the ROOT of your GitHub mfoni repository, alongside index.html and styles.css. Do NOT upload the enclosing folder. Images are referenced from the existing images/ directory.

Add navigation links to index.html: <a href="people.html">People</a> <a href="places.html">Places</a> <a href="moments.html">Moments</a>

The new pages have their own scoped layout styling and lightbox and do not require editing script.js.
